ŠPMC PWA – 3.1 versija (BANDYMAS)

1. Išskleiskite ZIP ir atidarykite index.html kompiuteryje – veiks peržiūra.
2. PWA įdiegimui reikia įkelti visą aplanką į HTTPS svetainę (pvz., GitHub Pages). Atidarius vietinį failą PWA įdiegimas ir automatiniai atnaujinimai neveiks.
3. Tvarkaraštis galioja 2026-10-05–2026-10-16. Duomenys nėra patvirtinti.
4. Neaiškūs įstrižiniai langeliai pažymėti tikrinimui, jų savaitės gali būti neteisingos. Žr. tikrintini_irasai.json.
5. tvarkarastis.json yra viešai skelbiamas tik patvirtinus; vėliau pakeitus šį failą GitHub Pages serveryje, prisijungusi programėlė gauna naujus duomenis.
6. Naujam Word importui reikės atnaujinto importavimo įrankio ir administratoriaus patvirtinimo. Šiame pakete yra dabartinis pavyzdinis duomenų rinkinys, o ne galutinė importavimo sistema.
